它做什么

🔌 6 源覆盖中外

HackerNews · 掘金 · SegmentFault · 知乎日报 · Reddit · B 站。全部 native HTTP scraper，零 LLM 抓取，新源 30 行 Python 接入。

📡 多用户订阅

朋友扫一个二维码就能加入。后台 SQLite 维护 binding 表，cron 一对多扇出。

🔄 双向交互

用户在微信回 查 GPT / 今天 / 帮助 / 退订，系统应答。

🛡 出站审核

敏感词命中即整批 abort + 告警，避免单条触发风控连累全号。

📊 仪表盘

本地 web UI 看订阅者、puller 状态、收发计数、强制退订、邀请订阅。

🔔 告警通道

飞书/钉钉/企微 webhook 上报 puller 失败、send 失败、内容拦截事件。

⏱ 速率限制

用户级 6/min + 全局 5/s 令牌桶，避开 iLink 风控阈值。

5 分钟起步

需要 Python 3.10+ 与 macOS 或 Linux。npm 包提供 praxdaily CLI。

# 1. 装 praxagent (iLink 客户端)
npm install -g praxagent

# 2. 装 praxdaily (npm 包)
npm install -g praxdaily

# 3. 进入工作目录，起本地面板
cd ~/your-workspace
praxdaily serve
# → http://127.0.0.1:7878/

# 4. 在面板里：
#    a) 微信账号屏：扫码登录一个 iLink bot
#    b) 通知渠道屏：新建 wechat_personal 渠道
#    c) 抓取源屏：配置 sources.yaml（HN + 关键词）
#    d) 订阅者屏：邀请朋友扫码订阅
#    e) 装 LaunchAgent: praxdaily install-schedule --time 14:00

进入「订阅者」屏点 + 邀请订阅 生成扫码二维码 → 朋友用微信扫 → 自动落 binding。次日 14:00 LaunchAgent 触发，朋友收到日报。

边界 + 风险

  • iLink 是非官方协议（reverse-engineered from Hermes-Agent）。商用合规需切公众号 + 多客服。
  • 协议号被封是常态（平均 1-3 月一次）。本项目内置告警，但没有号池自动 failover。
  • 不收集任何 SaaS 数据。所有 binding / messages 落本地 SQLite。
  • 这是个展示 / 自用项目。详见 README。
